# 暗夜幸存者 · 类吸血鬼幸存者 MVP

纯 HTML5 Canvas + 原生 JavaScript（ES Modules），零依赖、零构建，浏览器即开即玩。

## 快速开始

```powershell
node tools/serve.js
# 浏览器打开 http://localhost:5173
```

## 操作

- WASD / 方向键：移动
- 武器全自动攻击，无需手动操作
- 选卡（开局 / 升级时弹出）：**鼠标点击卡牌** 或 **按数字键 1-3**
- 死亡后按 R 重新开始

## 当前内容

### Step 1 · 核心循环

- 固定时间步长 game loop（逻辑 60Hz，渲染每帧）+ 相机平滑跟随
- 玩家移动、受击无敌帧、死亡判定
- 敌人在屏幕外生成并追击玩家；难度随时间爬升（刷怪间隔、数量上限、血量、伤害、速度）
- 敌人受击白闪 / 血条、玩家受击震屏
- 调试入口：浏览器控制台 `__game` 可查看/修改游戏状态

### Step 2 · 卡牌 / 经验 / 宝石（肉鸽成长循环）

- 敌人死亡掉落经验宝石，靠近自动吸附拾取；宝石价值随游戏时长提升
- 升级弹出「三选一」卡牌界面（选卡期间世界暂停）；一次升多级会连锁选卡
- 开局从 3 张武器卡中选 1 张；**武器槽上限 3**，走配置 `CONFIG.cards.maxWeaponSlots`（后续可扩展到 5，不写死）
- **武器卡（6 种，各 5 级，重复抽到同名卡 = 升级）**：
  - ⚔️ 道剑：朝最近敌人扇形挥砍，升级提升范围与伤害
  - 🔥 炽热披风：以玩家为中心的持续灼烧（纯持续伤害）
  - ⚡ 雷符咒：远程雷电弹道，受「弹道数量」属性加成
  - 🔥 丹火：移动时留下燃烧路径，敌人踩上持续扣血
  - 💍 玉环：围绕玩家旋转的玉环，触碰造成伤害
  - 💀 死灵法杖：周期性召唤仆从。仆从**无法被击杀**（无血条），但有固定存活时间；每个召唤槽位有独立内置 CD；不会离开玩家太远（leash）
- **属性卡（7 种，可重复抽取叠加，每种上限 5 层）**：
  - 伤害提升（每层 +15%）
  - 弹道数量（每层 +1 发，**只作用于有弹道的武器**）
  - 经验获取倍率（每层 +25%）
  - 武器范围（每层 +10%）
  - 移动速度（每层 +8%）
  - 攻速提升（每层 +10%）
  - 冷却时间（每层 -8%，影响披风灼烧 tick / 丹火残留 / 召唤内置 CD）
- HUD：顶部全宽经验条、等级、血条、武器槽（图标 + 等级）、计时、击杀数

## 项目结构

```
index.html            入口页面
js/
  main.js             启动、RAF 循环、固定时间步长
  game.js             游戏状态机（opening/playing/choice/dead）+ 碰撞 + 渲染分层
  config.js           全部平衡性数值
  input.js            键盘 + 鼠标输入
  camera.js           相机跟随
  player.js           玩家
  enemy.js            敌人（含防重叠推挤）
  spawner.js          屏外刷怪器（随时间加压）
  cards.js            卡牌定义（6 武器 + 7 属性）、卡池生成、属性乘数
  ui-cards.js         选卡界面（布局 + 渲染，鼠标命中共用布局）
  weapons.js          6 种卡牌武器实现
  projectile.js       子弹
  gems.js             经验宝石（吸附 / 拾取 / 档位）
  hud.js              HUD（经验条 / 武器槽）与死亡界面
tools/
  serve.js            静态服务器
  headless-smoke.mjs  无头冒烟测试
```
