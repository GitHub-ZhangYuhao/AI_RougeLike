# 1～25 波敌人难度系数配置表

## 规则

- 单局最多进行 **25 波**，每波固定持续 **90 秒**；普通波倒计时结束后直接进入下一波，不再以清空敌人作为推进条件。
- 每 5 波为 Boss 波，因此 Boss 波为：第 5、10、15、20、25 波。
- 下表系数由 `js/config.js` 中的波次成长参数计算；血量、移速和伤害系数由 `js/enemies/base.js` 的 `applyWaveScaling()` 应用于所有敌人。
- 血量、移速和伤害系数会继续与敌人存活时间成长、敌人类型系数相乘；Boss、精英和特殊怪仍会额外乘各自的类型系数。
- 数量系数以第 1 波计划投放的 16 个敌人为 `1.000`。计划数量会均匀分布在 90 秒内，用于控制投放密度，不再决定波次何时结束；同屏上限可能使实际生成数低于计划值。

## 计算方式

### 血量系数

- 第 1～6 波：每波 `+0.16`，比原前期曲线更快。
- 第 7～11 波：每波 `+0.30`，继续提高前中期压力。
- 第 12～25 波：每波 `+0.28`，后期增幅低于原来的 `+0.36`。
- 血量系数最大为 `7.000`。

### 移速系数

- 第 1 波的敌人基础移速系数为 `1.500`，即相对原始移速提升 **50%**。
- 第 1～20 波线性增长，每波约增加 `0.0263`。
- 第 20 波达到最大移速系数 `2.000`；第 20～25 波保持 `2.000`，不再增长。

### 数量系数

- 普通波数量系数从 `1.000` 开始，每波增加 `0.500`，最大为 `11.250`；对应计划数量会均匀投放到本波的 90 秒内。
- 第 22 波起普通波敌人数量达到上限 180。
- Boss 波使用独立配额：1 个 Boss，加上第 5/10/15/20/25 波的 4/6/8/10/12 个援军。

## 最终波说明

- 第 25 波是最终 Boss 波，由 1 个 Boss 和最多 12 个计划援军组成。
- Boss 波至少持续 90 秒；若倒计时结束时 Boss 仍存活，则进入超时阶段并停止继续投放，击败 Boss 后结算。
- 第 25 波倒计时结束且最终 Boss 已死亡后，本局直接进入通关结算。
- 通关会自动保存临时背包材料、发放暗晶奖励，并累计一次撤离和一次通关记录。
- 调试工具跳转到高于 25 的波数时会自动限制到第 25 波。

## 关联配置

- 最大波数与持续时间：`CONFIG.waves.maxWave`、`CONFIG.waves.duration`
- 全局移速提升：`CONFIG.enemy.baseSpeedMult`
- 血量成长与上限：`CONFIG.enemy.hpPerWave*`、`CONFIG.enemy.hpWaveCap`
- 伤害成长：`CONFIG.enemy.damagePerWave*`
- 移速成长与上限：`CONFIG.enemy.baseSpeedMult`、`CONFIG.enemy.speedWaveCap`、`CONFIG.enemy.speedCapStartWave`
- 数量成长与上限：`CONFIG.waves.quantityPerWave`、`CONFIG.waves.quantityWaveCap`
- 实际数量系数：`WaveDirector.quantityMultiplierFor()`
- 实际敌人属性系数：`js/enemies/base.js` 中的 `applyWaveScaling()`
