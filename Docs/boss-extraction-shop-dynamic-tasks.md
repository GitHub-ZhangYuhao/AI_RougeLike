# Boss 撤离、局外商城与随机动态任务

## 核心循环

局内战斗 → 随机动态任务 → Boss 战 → 获得临时战利品 → 选择撤离或继续 → 带出物品进入局外商城与仓库 → 准备下一局。

## Boss 撤离决策

- Boss 被击败后掉落物品，物品先进入**临时背包**。
- Boss 战结束后，玩家可以选择**撤离**或**继续深入**。
- 选择撤离：结束本局，临时背包中的物品成功带出并存入局外仓库。
- 选择继续：保留当前构筑和临时背包，进入后续阶段，并有机会获得更好的战利品。
- 继续深入后死亡：临时背包中的物品全部丢失。
- 已经成功带出并存入仓库的物品不会因后续游戏失败而丢失。

## 局外商城

- 商城使用成功撤离后带出的货币、材料或物品进行交易。
- 商城内容以**解锁玩法和提供构筑选择**为主，避免只提供永久数值增长。
- 可提供的商品类型：
  - 新武器、武器形态或联动模块。
  - 新遗物、事件、动态任务和敌人类型。
  - 下一局使用的一次性准备道具。
  - 开局刷新、锁定、排除或定向选择能力。
  - 图鉴、外观和展示内容。
- 商城商品会按照既定规则刷新，并保留获取指定内容的稳定渠道。
- 局外仓库用于保存已带出的物品，并为下一局选择准备内容。

## 随机动态任务

- 动态任务在普通战斗过程中随机产生，玩家可以自行决定是否参与。
- 任务不会中断原有战斗，而是在当前战场中增加额外目标。
- 任务失败不会直接结束本局，只会失去对应奖励或产生额外风险。
- 可用任务类型：
  - **悬赏追猎**：击杀指定强化敌人。
  - **守护祭坛**：保护目标或在指定区域作战。
  - **关闭裂隙**：前往不同位置关闭敌人生成点。
  - **资源运送**：取得资源并送往指定地点。
  - **限时生存**：在特殊规则下坚持到任务结束。
  - **护送救援**：保护目标抵达安全区域。
- 完成任务可获得临时战利品、局内强化、Boss 掉落加成或撤离相关奖励。
- 动态任务的目标、位置和危险需要有清晰提示，避免影响基础战斗信息读取。

## 系统关系

- 动态任务负责为普通波次提供额外目标和战利品来源。
- Boss 负责提供阶段性战利品与撤离决策。
- 撤离负责确认哪些物品可以进入局外仓库。
- 商城负责把成功带出的资源转化为新内容、构筑控制和下一局准备。
